The Daily Prophet · Project 02 · 5th Place

PhoniX Unmasks Deepfake Callers

An AI-powered vishing (voice-phishing) detection system that classifies live call audio to flag phishing calls.

How it works

  • A real-time dialer streams live audio for classification.
  • A deep-learning pipeline distinguishes authentic human speech from deepfake-generated audio.
  • Features are extracted from audio spectrograms.

Results

89.68% accuracy · 5th place, CSA Hackathon 3.0

Built with

Python · PyTorch · Audio Processing · Deep Learning

The Daily Prophet · Project 03 · Research

Recurrent KAN Predicts the Next Click

A next-item recommendation engine on sequential clickstream data, with three architectures implemented and benchmarked from scratch.

The work

  • Dataset: YooChoose — 50K sessions / 128K+ samples.
  • GRU baseline.
  • Pure recurrent KAN.
  • Hybrid GRU+KAN using learnable B-spline activations for better interpretability.

Results

58.08% HR@10 · 39.42% NDCG@10

Built with

Python · PyTorch · GRU + KAN · Deep Learning
